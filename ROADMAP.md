# Feuille de route

Les actions sont suivies dans les [issues](https://github.com/amineutron/lyra/issues) et regroupées par jalon.

- **v1.2 : vérifiable et installable** : licences et attributions complètes, flux de données documentés, paquet installable (`pip install lyra-assistant`), prérequis matériel, CI complète, aucun chemin personnel, démonstration visuelle.
- **v1.3 : reproductible** : mesures de performance datées et rejouables, test d'installation en machine virtuelle à chaque release, image de développement (devcontainer).
- **v2 : entreprise** : modèle d'agent MCP avec journal d'audit, droits par rôle et confirmation, backend LLM compatible OpenAI pour d'autres serveurs locaux, mode hors ligne.

Les issues marquées `good first issue` sont de bonnes portes d'entrée pour contribuer (voir [CONTRIBUTING](https://github.com/amineutron/.github/blob/main/CONTRIBUTING.md) et le [CLA](CLA.md)).
